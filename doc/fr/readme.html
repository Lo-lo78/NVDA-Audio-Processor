Processeur audio 1.0.60

Auteur : Lo-lo

Processeur audio est un processeur multieffet en temps réel pour l’audio de NVDA. Il intercepte l’audio envoyé par le chemin nvwave/WavePlayer de NVDA et peut traiter la parole, les sons NVDA, ou les deux.

Le processeur comprend High Pass, Low Pass, 4-band Parametric EQ, Master Gain, un 1176-style Compressor léger, Pan et Pan LFO, Stereo Chorus, Stereo Delay, Stereo Reverb et Limiter.

Limitation actuelle : la version 1.0.34 est destinée à NVDA 64 bits. Elle ne peut traiter que l’audio qui passe par nvwave/WavePlayer. Le bouton de diagnostic décrit plus loin permet de vérifier qu’un flux est bien intercepté.

Langues et terminologie

L’interface et la documentation sont disponibles en anglais, italien, espagnol et français. L’anglais est la langue source et de secours.

La terminologie audio/DSP standard et les noms des presets Factory restent volontairement en anglais dans toutes les langues, comme dans les VST classiques. Les textes d’interaction NVDA, messages, états, erreurs et explications sont traduits.

Démarrage rapide

  1. Appuyez sur NVDA+Alt+E pour ouvrir Processeur audio.
  2. Laissez cochée la case Traitement audio activé.
  3. Choisissez de traiter Tout l’audio de NVDA, Voix uniquement ou Sons uniquement.
  4. Essayez un preset Factory dans la liste Preset. Les presets sont appliqués immédiatement : le nom du preset est donc prononcé avec le son qui vient d’être chargé.
  5. Utilisez OK pour conserver les réglages actuels. Utilisez Annuler ou fermez la boîte de dialogue pour restaurer l’état qui était actif à son ouverture.

Boîte de dialogue principale

Utilisez Tab et Shift+Tab pour parcourir les contrôles. Les changements sont appliqués en temps réel : la parole suivante utilise immédiatement les réglages actuels.

NVDA Audio Device Lock

Lock NVDA Audio Device est désactivé par défaut, donc NVDA change de périphérique audio exactement comme d'habitude. Lorsque la case est activée, Tab amène à Audio Device, qui liste les sorties physiques actuellement actives. Audio Processor enregistre l'endpoint MMDevice/WASAPI sélectionné dans l'état complet du processeur et force les nouveaux WavePlayer de NVDA vers cet endpoint. Tant que le verrouillage est actif, changer le périphérique de sortie dans les paramètres Audio de NVDA ne déplace pas le chemin audio réel d'Audio Processor. En désactivant le verrouillage, le contrôle du routing revient immédiatement à NVDA.

Le verrouillage et l'endpoint sélectionné sont enregistrés dans les presets Utilisateur et les snapshots Custom Actions. Si un preset exige un endpoint verrouillé qui n'est pas disponible, Audio Processor annonce Audio device not available et n'applique aucune partie de ce preset : l'état précédent du processeur et du routing reste intact. Le sélecteur Preset reste sur le preset indisponible, de sorte qu'une nouvelle pression sur une flèche permet de continuer vers le preset précédent ou suivant.

Liste Preset

La liste Preset contient Réglages actuels, 32 presets D’usine et les presets Utilisateur que vous créez. Les flèches chargent immédiatement le preset sélectionné. Si vous modifiez manuellement un paramètre, la liste revient à Réglages actuels.

  • Ctrl+S : ouvre Enregistrer le preset sous, demande un nom, enregistre l’état complet du processeur et sélectionne immédiatement le nouveau preset Utilisateur.
  • F2 : renomme le preset Utilisateur sélectionné. Les presets Factory ne peuvent pas être renommés.
  • Delete : supprime le preset Utilisateur sélectionné après confirmation Oui/Non. Les presets Factory ne peuvent pas être supprimés.
  • Si un preset Utilisateur du même nom existe déjà, Processeur audio demande confirmation avant de le remplacer.

Champs numériques

Les paramètres numériques sont des listes déroulantes éditables. Vous pouvez saisir directement une valeur ; la virgule et le point sont acceptés comme séparateur décimal. Les changements au clavier sont appliqués en temps réel.

  • Flèche haut : augmente selon le pas actuel.
  • Flèche bas : diminue selon le pas actuel.
  • Page précédente : augmente de dix fois le pas actuel.
  • Page suivante : diminue de dix fois le pas actuel.
  • Alt+A : sélectionne un pas plus petit pour le paramètre numérique ayant le focus.
  • Alt+S : sélectionne un pas plus grand pour le paramètre numérique ayant le focus.

Sections de traitement et plages des paramètres

L’ordre du chemin dry est : High Pass → 4-band Parametric EQ → Low Pass → Master Gain → 1176 Compressor → Pan/Pan LFO → Limiter. Stereo Chorus reste un send aux parallèle. Stereo Delay et Stereo Reverb forment une chaîne série dont l’ordre est sélectionnable après Pan/Pan LFO : le premier effet reste audible et alimente aussi le second, tandis que le dry reste à plein niveau. Delay before Reverb décoché = Reverb → Delay ; coché = Delay → Reverb. Chain Blend contrôle la part du premier effet qui reste directement audible lorsque Delay et Reverb sont actifs : 0 conserve le mix précédent, tandis qu’à 100 le premier effet est entendu uniquement après être passé dans le second. Tous les retours wet sont sommés échantillon par échantillon dans le même buffer master WavePlayer.

Sélecteur Process

  • Tout l’audio de NVDA : traite la parole et les sons NVDA.
  • Voix uniquement : traite uniquement les flux de parole.
  • Sons uniquement : traite uniquement les flux de sons NVDA.

Traitement stéréo

Si la voix est mono, Processeur audio passe le WavePlayer source en stéréo lorsque Pan, Pan LFO ou un send audible Chorus, Delay ou Reverb exige la stéréo. Dry et wet partagent ainsi le même WavePlayer, la même horloge et la même file, empêchant un ancien effet de rester sous la parole suivante. Le chemin vocal est ainsi moins modifié tout en conservant des échos et une ambiance stéréo.

Comportement des Send et des queues : Chorus, Delay et Reverb restent des sends parallèles et leurs retours wet en direct sont mélangés dans le même WavePlayer source. Delay Tail et Reverb Tail sont indépendantes et désactivées par défaut. Lorsqu’une queue est activée, Audio Processor ne crée pas de second player wet et ne reconstruit pas l’effet : après la fin de l’audio source, il fait continuer la même mémoire Delay/Reverb en alimentant du PCM numériquement silencieux dans le même WavePlayer. La durée suit Delay Time/Feedback et Reverb Decay/Size, avec détection du silence et une limite de sécurité. Pour la parole utilisant le mixer FIFO, un Ctrl/stop explicite est une interruption complète : la parole en file et les queues wet activées sont vidées immédiatement. Lorsqu’une nouvelle parole arrive naturellement pendant la décroissance d’une queue, le wet déjà mis en file est vidé mais la mémoire Delay/Reverb est conservée ; la nouvelle phrase entre donc dans le même espace acoustique sans attendre derrière la queue. IBM ECI/IBM TTS utilise une règle de compatibilité : les énoncés de 350 ms PCM ou moins ne démarrent pas de queue Delay/Reverb après la parole, tandis que les effets restent pleinement actifs pendant l’énoncé lui-même ; les paroles IBM plus longues utilisent normalement les queues.

Report intercepted audio format

Le bouton Annoncer le format audio intercepté donne des informations sur le dernier flux intercepté : parole/sons, sample rate, bit depth, nombre de canaux et état actuel du traitement. Il est utile pour tester un synthétiseur ou une configuration audio.

Le DSP accepte les flux PCM interceptés en 8, 16, 24 ou 32 bits.

Fichiers utilisateur

La configuration principale est enregistrée dans le dossier de configuration utilisateur de NVDA. Les presets Utilisateur sont des fichiers JSON stockés dans un sous-dossier presets à l’intérieur du dossier localisé de Processeur audio :

  • Anglais : Audio Processor\presets
  • Italien : Processore audio\presets
  • Espagnol : Procesador de audio\presets
  • Français : Processeur audio\presets

Le nom du dossier suit la langue actuelle de l’interface NVDA. Si vous changez de langue et souhaitez utiliser les mêmes presets Utilisateur, copiez les fichiers JSON vers le dossier de presets correspondant à la nouvelle langue.

Notes

  • Les noms DSP standard restent en anglais par choix de conception.
  • Les presets Factory sont protégés contre le renommage et la suppression.
  • Les modifications manuelles sont live ; OK les rend permanentes, tandis qu’Annuler restaure les réglages présents à l’ouverture de la boîte de dialogue.
  • Le Limiter est activé dans la configuration par défaut.
