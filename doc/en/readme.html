Audio Processor 1.0.62

Author: Lo-lo

Audio Processor is a real-time multi-effect processor for NVDA audio. It intercepts audio sent through NVDA's nvwave/WavePlayer path and can process speech, NVDA sounds, or both.

The processor includes resonant High Pass and Low Pass, four-band Parametric EQ, Master Gain, a lightweight 1176-style Compressor, a shared LFO with independent Pan/Low Pass/High Pass Depth controls, Stereo Chorus, Stereo Delay, Stereo Reverb and Limiter.

Current limitation: version 1.0.34 is intended for 64-bit NVDA. It can only process audio that reaches NVDA through the nvwave/WavePlayer path. The diagnostic button described below can help verify that a stream is being intercepted.

Languages and terminology

The add-on interface and documentation are available in English, Italian, Spanish and French. English is the source/fallback language.

Standard audio/DSP terminology and Factory preset names intentionally remain in English in every locale, as in conventional VST plug-ins. NVDA interaction text, messages, states, errors and explanations are translated.

Quick start

  1. Press NVDA+Alt+E to open Audio Processor.
  2. Leave Audio processing enabled checked.
  3. Choose whether to process All NVDA audio, Speech only or Sounds only.
  4. Try a Factory preset from the Preset combo box. Presets are applied immediately, so the preset name is heard through the newly loaded sound.
  5. Use OK to keep the current settings. Use Cancel or close the dialog to restore the state that was active when the dialog was opened.

Main dialog

Use Tab and Shift+Tab to move through controls. Changes are applied live, so the next speech is heard with the current settings.

NVDA Audio Device Lock

Lock NVDA Audio Device is off by default, so NVDA changes audio devices exactly as usual. When the check box is enabled, Tab moves to Audio Device, which lists the currently active physical output endpoints. Audio Processor stores the selected MMDevice/WASAPI endpoint as part of the complete processor state and forces new NVDA WavePlayers to that endpoint. While the lock is active, changing the output device in NVDA settings does not move the actual Audio Processor audio path. Turning the lock off immediately returns routing control to NVDA.

The lock and selected endpoint are saved inside User presets and Custom Actions snapshots. If a preset requires a locked endpoint that is not currently available, Audio Processor announces Audio device not available and does not apply any part of that preset: the previously active processor and routing state remains unchanged. The Preset selector stays on the unavailable preset, so another arrow press can continue to the next or previous preset.

Preset combo box

The Preset combo contains Current settings, 32 Factory presets and any User presets you create. Moving with the arrow keys loads the selected preset immediately. If you manually edit any processor parameter, the combo returns to Current settings.

  • Ctrl+S: opens Save As, asks for a name, saves the complete processor state and immediately selects the new User preset.
  • F2: renames the selected User preset. Factory presets cannot be renamed.
  • Delete: deletes the selected User preset after a Yes/No confirmation. Factory presets cannot be deleted.
  • If a User preset with the same name already exists, Audio Processor asks before replacing it.

Numeric fields

Numeric parameters are editable combo boxes. You may type a value directly; both comma and period are accepted as decimal separators. Keyboard changes are live.

  • Up Arrow: increase by the current step.
  • Down Arrow: decrease by the current step.
  • Page Up: increase by ten times the current step.
  • Page Down: decrease by ten times the current step.
  • Alt+A: choose a smaller available step for the focused numeric parameter.
  • Alt+S: choose a larger available step for the focused numeric parameter.

Reverb Type (TEST62)

Under Stereo Reverb, the Reverb Type choice follows Reverb tail enabled. Use Up/Down to choose Classic, Room, Chamber, Hall, Cathedral, Plate or Spring. Classic preserves the original TEST61 sound; the other modes use distinct feedback delays and diffusion. Reverb Size, Decay, Damping and Send work with every type. Mode changes are live and persist in settings, user presets and Custom Actions. Old presets without a type are Classic. Spring is a lightweight digital spring-inspired sound rather than a hardware spring-tank simulation. The NVDA Input Gestures dialog includes next/previous Reverb Type commands.

Processing sections and parameter ranges

The dry processing order is: High Pass → 4-band Parametric EQ → Low Pass → Master Gain → 1176 Compressor → Pan/Pan LFO → Limiter. Stereo Chorus remains a parallel aux send. Stereo Delay and Stereo Reverb form an orderable serial send chain after Pan/Pan LFO: the first effect remains audible and also feeds the second, while the dry signal stays at full level. Delay before Reverb Off = Reverb → Delay; On = Delay → Reverb. Chain Blend controls how much of the first effect remains directly audible when both effects are active: 0 keeps the previous return mix, while 100 hears the first effect only after it has passed through the second. All wet returns are summed sample-accurately back into the same master WavePlayer buffer.

Process selector

  • All NVDA audio: process both speech and NVDA sounds.
  • Speech only: process speech streams only.
  • Sounds only: process NVDA sound streams only.

Stereo processing

If speech is mono, Audio Processor promotes the source WavePlayer to stereo whenever Pan, Pan LFO or an audible Chorus, Delay or Reverb send requires stereo. Dry and wet then share the same WavePlayer, clock and queue, so an effect buffer from an older phrase cannot continue underneath later speech.

Send and tail behavior: Chorus, Delay and Reverb remain parallel sends and their live wet returns are mixed into the same source WavePlayer. Delay Tail and Reverb Tail are independent and Off by default. When enabled, Audio Processor does not create a second wet player or reconstruct the effect: after source audio ends it keeps the same Delay/Reverb memory advancing with digital-silent PCM on the same WavePlayer. Duration follows Delay Time/Feedback and Reverb Decay/Size, with quiet detection and a safety limit. For speech that uses the FIFO mixer, an explicit Ctrl/stop is a hard interruption: queued speech and enabled wet tails are flushed immediately. When new speech arrives naturally while a tail is decaying, stale queued wet audio is flushed but the Delay/Reverb memory is preserved, so the new phrase enters the same acoustic state without waiting behind the tail. IBM ECI/IBM TTS uses one compatibility rule: utterances of 350 ms PCM or less do not start a post-speech Delay/Reverb tail, while the effects remain fully active during the utterance itself; longer IBM speech uses normal tails.

Report intercepted audio format

The Report intercepted audio format button announces information about the most recently intercepted stream, including speech/sounds purpose, sample rate, bit depth, channel count and the current processing state. This is useful when testing a synthesizer or audio configuration.

The DSP supports intercepted PCM streams with 8, 16, 24 or 32-bit samples.

User files

The main processor configuration is stored in the NVDA user configuration folder. User presets are JSON files stored in a presets subfolder under the localized Audio Processor folder:

  • English: Audio Processor\presets
  • Italian: Processore audio\presets
  • Spanish: Procesador de audio\presets
  • French: Processeur audio\presets

The folder name follows the current NVDA interface language. If you change NVDA language and want the same User presets in the new language, copy the preset JSON files to that language's Audio Processor preset folder.

Notes

  • The add-on keeps standard DSP names in English by design.
  • Factory presets are protected from rename and deletion.
  • Manual edits are live; OK commits them, while Cancel restores the settings that were active when the dialog opened.
  • The Limiter is enabled in the default configuration.
